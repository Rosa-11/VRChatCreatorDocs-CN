# VRChatCreatorDocs-CN
VRC开发者文档中文翻译版
- markdown格式的笔记放在[docs/](https://github.com/Rosa-11/VRChatCreatorDocs-CN/tree/main/docs)目录
- 双击 RunDocsPreview.cmd 打开本地网页版，查阅更方便。首次运行需要安装依赖可能会比较慢。
- 网页版默认使用本地 3000 端口，若端口被占用可以按照提示切换到其他端口，如 3001
- 使用 DeepSeek v4.1 flash 提供的翻译。
- 网页前端使用 Docusaurus 构建，这是一个把 markdown 文件转化成网页的工具。
- 修改文档内容后要重新启动才能在网页前端看到，每次启动时会重新编译构建。
