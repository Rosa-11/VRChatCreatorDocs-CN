# 商店 {#stores}

import SellerNotification from '/docs/economy/_sellers-notification.mdx';

<SellerNotification/>

商店让用户可以轻松在 VRChat 中发现你的[商品](../listings)和[订阅](../subscriptions)。你可以拥有多个商店，也可以将商品发布到多个商店中。

import DocCardList from '@theme/DocCardList';

<DocCardList />

:::info

你可以使用 [Udon](/economy/sdk/udon-documentation) 来出售你已发布的商品和订阅——即使你并没有将它们发布在你的商店中。

:::
