# 虚拟形象市场 {#avatar-marketplace}

import SellerNotification from '/docs/economy/_sellers-notification-avm.mdx';

<SellerNotification/>

虚拟形象（Avatar）市场包含可在 VRChat 中购买的[虚拟形象产品](/economy/products/avatar)。这是发现、购买和出售 VRChat 虚拟形象最便捷的方式。

## 浏览市场 {#browse-the-marketplace}

虚拟形象市场位于 VRChat 菜单的「Avatars」部分。用户可以浏览市场、搜索已发布的虚拟形象，并查看它们的[详细信息](/economy/products/avatar#avatar-details)。选择任何虚拟形象产品都会将用户带到其详细信息页面。

## 在市场发布虚拟形象 {#publish-an-avatar-on-the-marketplace}

按照以下步骤在市场发布你的虚拟形象：

1. 上传一个[虚拟形象](/avatars/creating-your-first-avatar)。
2. 创建一个[虚拟形象产品](/economy/products/avatar)。
3. 等待 VRChat 审核并接受你的虚拟形象产品。
4. 创建一个[商品](/economy/listings)。
5. 将你的虚拟形象产品添加到你的商品中。
6. 发布你的商品。
7. （可选）将你的商品添加到[世界商店](/economy/store/world-store)。

现在，用户可以在 VRChat 中购买你的虚拟形象，并在市场上发现它。

## 成为虚拟形象卖家 {#become-an-avatar-seller}

只有获得授权的虚拟形象卖家才能在市场上创建和发布虚拟形象产品。要成为获得授权的虚拟形象卖家，请[提交申请](https://www.surveymonkey.com/r/MC5X89R)。我们会随着时间推移逐步授权更多虚拟形象卖家。

 如果你已经是创作者经济中的卖家，并希望获得虚拟形象市场的访问权限，请提出申请。
