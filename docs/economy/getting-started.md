# Tilia入门 {#getting-started-with-tilia}

<SellerNotification/>

在使用创作者经济（Creator Economy）之前，你需要向VRChat的支付合作伙伴Tilia请求授权。Tilia通过验证你的身份、遵守当地法律以及检测欺诈，确保你拥有安全的销售体验。

要开始使用，请观看视频或阅读以下步骤：

:::

## 第1步：打开我的商店 {#step-1---open-my-store}

打开[VRChat.com](https://vrchat.com/home)，前往左侧边栏中的[我的商店](https://vrchat.com/home/marketplace/)标签页，然后打开你的[商店页面](https://vrchat.com/home/marketplace/storefront)。

![市场](/img/economy/GettingStarted-Marketplace.png "导航到商店页面标签页")

## 第2步：开始使用 {#step-2---get-started}

点击**Get Started with Tilia**。

## 第3步：验证身份 {#step-3---verify-identity}

阅读Tilia的**服务条款**和**隐私政策**后，请务必勾选**“我同意”**。然后填写以下部分并提交，以验证你的信息。

![Tilia页面](/img/economy/GettingStarted-Tilia.png "查看Tilia的条款并验证信息。")

确保你的个人信息正确无误！否则，你可能无法使用创作者经济。

## 第4步：等待 {#step-4---wait}

等待Tilia接受你的信息。这通常需要约5个工作日，但极少数情况下可能需要长达30个日历日。

:::info

如果Tilia接受你的时间比预期更长，请尝试以下步骤：

- 重复[第2步](#step-2---get-started)，然后再次点击“Get Started with Tilia”。
	- Tilia可能已经接受了你。如果是这样，点击“Get Started”可能会让VRChat检查你的接受状态，并将你重定向到商店页面。
- 检查你的收件箱。
	- 你可能已经被接受，也可能存在问题。Tilia可能会通过电子邮件联系你
- 如果你仍然遇到技术问题，请联系Tilia或VRChat。

:::

## 第5步：已接受 {#step-5---accepted}

一旦你被接受，**商店页面**现在会显示你已**获得授权**在VRChat中销售！从现在起获得的任何点数都将有资格获得[结算](/economy/payout)。

![现已获得授权](/img/economy/GettingStarted-Storefront-Authorized.png "已获得在VRChat中销售的授权")

你现在可以创建[产品](./products)、[订阅](./subscriptions)、[商品](./listings)和[商店](./store)了！

一旦你赚取了足够的点数，就可以[结算你的收入]并连接你的PayPal账户。
