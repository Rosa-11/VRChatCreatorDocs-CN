### 如何导入 {#how-to-import}
1. 从 Unity 编辑器菜单的“VRChat SDK > 🏠 Example Central”中打开 [Example Central 窗口](/sdk/example-central)
2. 如果你尚未启用 Creator Economy 示例：
    1. 点击 Example Central 窗口中的 ⚙️ 齿轮图标，打开 Example Central 设置。
    2. 启用“Show Creator Economy Examples”。
3. 在 Example Central 中选择此预制件。
4. 点击“Import”按钮，将示例资源导入你的项目。
