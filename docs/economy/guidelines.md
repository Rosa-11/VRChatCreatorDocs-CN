# 内容指南 {#content-guidelines}

通过VRChat创作者经济销售内容的创作者必须遵守以下规则和指南。

:::note

这些指南中的规则可能会随着VRChat不断探索新的实现方式和用例而发生变化。如果你有任何疑问或顾虑，请随时直接询问我们！

:::

## 通用 {#general}
1. 你必须遵守VRChat的[服务条款](https://hello.vrchat.com/legal)。
	1. 这包括[创作者经济计划规则](https://hello.vrchat.com/legal/economy)、[社区指南](https://hello.vrchat.com/community-guidelines)和[创作者指南](https://hello.vrchat.com/creator-guidelines)。
	2. 你只能销售你完全拥有或拥有合法分发权利的内容，包括任何第三方元素。确保你拥有必要的许可或权限。（参见VRChat[服务条款](https://hello.vrchat.com/legal)第8.4节）
2. 如果发现你的内容违反了VRChat的[服务条款](https://hello.vrchat.com/legal)或本页列出的任何内容指南，你必须在通过电子邮件收到问题通知后的10天内尽合理努力解决该违规行为。
	1. 例如，如果你的虚拟形象（Avatar）包含市场上不允许的内容，你必须在收到通知后的10天内尽合理努力上传移除此内容的新Avatar构建。
3. 明确说明用户购买的是什么。
	1. 商品、订阅和产品必须具有清晰的名称和足够详细的描述。
	2. 内容必须避免使用[暗黑模式](https://en.wikipedia.org/wiki/Dark_pattern)或欺骗性设计模式，例如误导和诱饵调包。
	3. 商品和订阅必须准确反映买家将获得的内容。名称、标签、描述、致谢信息、图片和预览（包括缩略图）不得具有误导性。请记住，如果你的内容在VRChat中看起来与你用来展示它的图片不同，买家可能会感到失望。
	4. 包含不同类型产品的商品必须明确说明这些产品可以在哪里使用。例如，如果你销售包含[虚拟形象产品](/economy/products/avatar)*和*[Udon产品](/economy/products/udon)的捆绑包，请确保买家明白，虽然他们可以在任何地方使用这些虚拟形象，但Udon产品只能在特定的世界中使用。
	5. 如果你的内容在不同平台上的功能有所不同，你必须向买家说明这一点。例如，如果某些功能是PC独占的，请在产品描述中说明。
4. 如果存在功能对等，除任何平台外变现方式之外，你还必须使用创作者经济。
	1. 例如，如果你通过平台外服务为你的VRChat世界销售权益，那么在可能的情况下，你也必须允许用户通过创作者经济购买这些权益。
	2. 不要为你的外部产品定价以驱使VRChat用户离开平台。
	3. 如果你无法在VRChat内部复制相同的外部变现产品（例如虚拟形象源文件下载），这些规则可能不适用于你。欢迎探索创作者经济当前提供的功能。如果VRChat目前不支持你的变现方式，请尽力尝试，并提交[功能请求](https://feedback.vrchat.com/creator-economy)。
5. 不要将VRChat的创作者经济系统用作你外部变现产品的营销工具。
	1. 例如，不要促使客户退款并改用其他支付方式。
	2. 例如，不要利用你的商品描述在其他平台上宣传更低的价格。
	3. 例如，不要鼓励用户在其他平台购买你的内容，以便他们能够获取源文件。
6. 不要将VRChat点数用作筹款方式。
	1. 筹款支付方式必须在VRChat平台之外托管。
	2. 你可以为未通过创作者经济资助的外部筹款活动请求捐赠。
	3. 你可以通过你的支持者请求捐赠，不过针对筹款活动和慈善组织的捐赠在不同国家/地区的征税方式往往不同，并且只能使用法定货币进行管理。
7. 费用必须始终以“VRChat Credits”、“Credits”、VRChat点数图标<ThemedCreditIcon/>，
 或“\V”显示。
	1. 许多用户位于不同国家/地区，并使用不同货币购买VRChat点数。请使用上述术语，向买家准确传达你产品的费用。

## 世界 {#worlds}
1. 世界不得宣传涉及真实货币的彩票、抽奖或其他“机会游戏”。
	1. 禁止任何以赌博、赌场式活动或真实世界利益方式与真实世界货币集成的系统。
2. 你不得在用户未购买的情况下，让你的世界给用户带来完全负面的体验。
	1. 例如，你可以阻止访问你世界中的付费内容，但你必须说明他们为什么无法访问，和/或允许他们购买访问权限。
3. 你的[即时](/economy/listings#instant)商品、[临时](/economy/listings#temporary)商品和[订阅](/economy/subscriptions)的定价不得超过10,000<ThemedCreditIcon/>。
## 虚拟形象 {#avatars}
1. 你的虚拟形象必须经过优化，并且不得在VRChat中造成显著的性能问题。
	1. 你的虚拟形象的性能等级必须为“Excellent”、“Good”、“Medium”或“Poor”。 
	2. “Very Poor”虚拟形象仅按个案接受。
2. 你的虚拟形象必须具有高度的视觉和技术保真度。
	1. 如果你的虚拟形象在多个平台（PC、Android、iOS）上可用，其外观在所有平台上必须相似。
	2. 如果你的虚拟形象使用[表情菜单](/avatars/expression-menu-and-controls/)或[组件](/common-components/)，请避免技术问题或错误。
3. 你的虚拟形象的更新必须仅限于错误修复、性能改进和新功能/改进功能。
	1. 如果你想对已经购买的基础虚拟形象进行明显且实质性的更改，请联系VRChat经济团队进行讨论。我们可能会在未来调整此政策。
4. 你的虚拟形象不得使用碰撞体或[站点](/worlds/components/vrc_station/)来飞行、传送或比其他VRChat虚拟形象移动得更快。
	1. 例如：你可以使用GoGo Loco，但不能使用GoGo Flight。
5.  如果你的商品包含[虚拟形象产品](/economy/products/avatar)，则商品中每个不同虚拟形象产品的价格必须至少为600<ThemedCreditIcon/>，不包括同一虚拟形象的变体。例如：
	1. 如果你的商品包含两个不同的虚拟形象，其价格必须至少为1,200<ThemedCreditIcon/>（600<ThemedCreditIcon/> × 2）。
	2. 如果你的商品包含同一虚拟形象的两个变体，即不同颜色或服装，其价格必须至少为600<ThemedCreditIcon/>。
	3. 如果你的商品包含单个虚拟形象，其价格必须至少为600<ThemedCreditIcon/>。
6. 你的虚拟形象必须遵守下方的虚拟形象内容指南。
	1. 如果你的商品包含虚拟形象产品和Udon产品，请确保Udon产品也符合下方的内容指南。

:::info

尽管满足上述所有标准，VRChat仍可能拒绝某些虚拟形象。VRChat目前只接受有限数量的虚拟形象。高质量虚拟形象更有可能被接受。
 
未来这一限制会变得不那么严格。请访问我们的虚拟形象卖家Discord社区以获取更多信息。  

:::


### 虚拟形象内容指南 {#avatar-content-guidelines}

以下指南说明了哪些类型的内容适合虚拟形象市场。这些内容指南适用于虚拟形象的所有配置和查看选项。在替代状态或查看模式中违反这些指南的内容（例如通过开关隐藏、隐藏在纹理中，或以其他方式“锁定”使用户无法访问）是不允许的。
 
#### 属性 {#properties}

1. 你的虚拟形象在市场上的名称、描述、标签、致谢信息、图片和预览必须遵守VRChat的虚拟形象[公共内容指南](https://hello.vrchat.com/creator-guidelines)。  
2. 英语必须是你的虚拟形象属性、纹理或表情菜单中所有文字或字符的主要语言。  
    - 你可以添加额外的非英语翻译（附英语对应内容）。  
    - 例如：你的表情菜单中的文字必须是英语，但你可以使用图标来提供日语翻译。
3. 你的虚拟形象的名称必须以字母数字字符开头。例如：
	- ✅Alice - Astronaut
	- ✅8-Bit Bob!!!
	- ❌- Alice - Astronaut
	- ❌!!!8-Bit Bob!!!
#### 服装与外观 {#clothing--appearance}

你的虚拟形象必须适当遮盖私密部位，或以非性化的方式呈现。

市场允许创意和风格化，但虚拟形象必须避免传达明显的性意味或裸体。例如，带有图案纹理的私密部位可能传达出被遮盖的感觉，而类似皮肤的平面着色可能暗示裸体。

|                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **此内容可以在市场上销售。**                     | <ul><li>泳装、内衣</li><li>奇幻服装</li><li>不过分暴露的得体服装</li><li>暗示有遮盖的躯干（例如机器人装甲、毛皮或其他风格化设计）</li></ul>                                                                                                                                                                                         |
| **此内容在市场上的可见度可能较低。**[^1] | <ul><li>暴露或紧身的服装</li></ul>                                                                                                                                                                                                                                                                                                                                                       |
| **此内容不允许在市场上销售。**[^1]            | <ul><li>性暗示裸体</li><li>可见或夸张的性特征</li><li>主要为性吸引力而设计的极端身体夸张</li><li>性感内衣</li><li>暗示性动画</li><li>传达裸露感或性意味的暴露胸部</li><li>暴露或夸张的臀沟</li><li>穿着服装的虚拟形象上具有性暗示的下胸暴露</li></ul> |


#### 武器与暴力 {#weapons--violence}

你的虚拟形象可以包含卡通化或风格化的武器，但不得描绘写实的暴力。

|                                                                      |                                                                                                           |
| -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **此内容可以在市场上销售。**                     | <ul><li>风格化和玩具般的武器（例如剑、盾、弓、泡泡枪）</li></ul>                |
| **此内容在市场上的可见度可能较低。**[^1] | <ul><li>写实枪械</li><li>军事装备</li></ul>                                                |
| **此内容不允许在市场上销售。**[^1]            | <ul><li>血腥暴力（例如血迹飞溅）</li><li>伤害、折磨或死亡的描绘</li></ul> |


#### 恐怖与黑暗主题 {#spooky--dark-themes}

轻微的恐怖元素可以接受，但必须避免极端内容。

|                                                                      |                                                                                                                                                                                             |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **此内容可以在市场上销售。**                     | <ul><li>轻度惊悚设计（例如骷髅、发光的眼睛）</li></ul>                                                                                                                     |
| **此内容在市场上的可见度可能较低。**[^1] | <ul><li>令人不安或阴森的设计</li></ul>                                                                                                                                             |
| **此内容不允许在市场上销售。**[^1]            | <ul><li>极端恐怖（例如残害、怪诞图像、写实的悲剧事件）</li><li>毒品或犯罪活动的提及</li><li>真实世界悲剧的提及</li></ul> |

#### 音频源 {#audio-sources}
   
你的PC虚拟形象可以使用音频源，但它们不得具有侵扰性。

|                                                           |                                                                                                                                                            |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **此内容可以在市场上销售。**          | <ul><li>音效、交互声音或短音效</li><li>低范围和音量的持续、循环或环境声音</li></ul>                  |
| **此内容不允许在市场上销售。**[^1] | <ul><li>可能让其他用户感到不适的嘈杂或压迫性声音</li><li>其他用户在远距离可听到的循环声音或音乐</li></ul> |
  

#### 侵扰性功能 {#intrusive-features}

你的虚拟形象不得对其他VRChat玩家的体验产生负面影响。

|                                                           |                                                                                                                                                                                                         |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **此内容可以在市场上销售。**          | <ul><li>临时或部分隐身</li><li>允许其他玩家紧密跟随你的虚拟形象根变换的[站点](/worlds/components/vrc_station/)（例如马或机甲）</li></ul> |
| **此内容不允许在市场上销售。**[^1] | <ul><li>持续完全隐身</li><li>允许异常移动（例如飞行、传送、穿墙）的碰撞体、站点或其他功能</li></ul>                                 |

[^1]: 你的虚拟形象缩略图不得包含任何此类内容。

## 处罚 {#enforcement}
违反上述指南可能会导致对你的账户采取以下措施：

- 你的内容或商店可能会被临时或永久移除。
- 你销售内容的权限可能会被临时或永久撤销。
- 你的用户账户可能会被临时或永久封禁。
