## 添加预制件 {#adding-prefabs}

每个预制件都共享相同的起始步骤：

1. 下载你需要的预制件的 Unity 包，可以在左侧边栏中找到它。

2. 将该包导入你的 Unity 项目。

![DragAndDrop](/img/economy/examples/Importing-Package_Drag-and-Drop.png "将你的预制件拖入 Unity。")

3. 将该预制件拖入你的场景。

![ImportPrefabtoUnity](/img/economy/examples/Importing-Package_Place-In-Scene.png "将你的预制件拖入场景。")

然后你就可以自定义了！在左侧边栏中浏览我们不同的预制件，了解它们的功能以及如何自定义它们。
