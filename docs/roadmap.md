# 路线图 {#roadmap}

:::note 

本页最后更新于2026年8月31日，内容可能已过时。如需获取最新信息，请访问VRChat的[反馈板](https://feedback.vrchat.com/)、[论坛](https://ask.vrchat.com/c/official/31)和[SDK发布说明](/releases/)。

:::
