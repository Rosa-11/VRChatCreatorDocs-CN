# 头部切除 {#head-chop}

佩戴虚拟形象（Avatar）时，VRChat会通过将Avatar头部骨骼的Transform缩放设为接近0来自动“切除”其头部。这样可以防止头部从用户的第一人称视角中穿入视野。`VRCHeadChop`是一个可选的Avatar组件，用于控制哪些特定骨骼会在头部切除时被缩小，从而使Avatar创作者可以：
- 让Avatar头部的某些部分在第一人称视角中保持可见，例如头发或鼻子。
- 在第一人称视角中隐藏Avatar上不属于头部的部分，例如兜帽。

`VRCHeadChop`只影响佩戴它的用户视角中的Avatar外观。它不会影响Avatar在镜子中或对其他玩家显示的样子。

## 组件属性 {#component-properties}
![Unity检视面板中的VRC Head Chop组件](/img/avatars/vrcheadchop-f0de7579-2024-03-15_19-46-28_Unity.png)

下表列出了你可以配置的所有参数：

| 属性 |  | 描述 |
| ---- | ---- | ---- |
| **Target Bones** |  | 用于通过此组件控制的骨骼列表，最多32根。每根骨骼都可以单独配置： |
|  | *Transform* | 骨骼Transform。 |
|  | *Scale Factor* | 设置要应用于此骨骼的缩放。<br/>如果缩放系数为0，骨骼将被完全隐藏。<br/>如果缩放系数为1，骨骼将完全可见。（默认） |
|  | *Apply Condition* | 控制在哪些条件下应将缩放应用于Transform。<br/>- 始终应用（默认）<br/>- 仅VR<br/>- 仅非VR |
| **Global Scale Factor** |  | 乘以每个目标骨骼的缩放系数。通常可以将其保持为1，除非你想一次性缩放所有骨骼。<br/>如果全局缩放系数为1，每个目标骨骼将使用其各自的缩放系数。（默认）<br/>如果全局缩放系数为0，所有目标骨骼的缩放系数都将为0。 |

:::info 使用提示

- 更改父骨骼的`VRCHeadChop`设置也会影响所有子骨骼。
- 如果子骨骼有自己的`VRCHeadChop`设置，则会覆盖其父骨骼的设置。
- 你的Avatar上最多可以附加16个`VRCHeadChop`组件。如果超过此限制，Avatar SDK将显示错误。
- 如果你使用`VRCHeadChop`，“Lock Hip”[锁定类型](https://docs.vrchat.com/docs/ik-20-features-and-options#lock-types)可能会导致你的Avatar头部遮挡你的视野。

:::

## 基本用法 {#basic-use}

使用`VRCHeadChop`最常见的方式是让你的Avatar头发保持可见。在大多数Avatar上，头发骨骼是Avatar头部骨骼的子级。

1. 将希望保持可见的骨骼添加到“Target Bones”列表。
2. 将其缩放系数设为1。
3. （可选）如果你不希望这些骨骼对非VR玩家可见，将“Apply condition”设为“VR Only”。

这会使头发骨骼在你的第一人称视角中完全可见。头部的其余部分以及所有其他子骨骼将保持隐藏。

例如，SDK附带的示例Avatar Dynamics机器人有头发和一对动物耳朵。我们可以使用以下设置，让头部的这些部分在第一人称视角中保持可见，同时隐藏头部的其余部分。在此示例中，我们还把应用条件设为“VR Only”，因此这些额外部分只会在VR中游玩时出现。

![vrcheadchop-618b6e18-2024-02-06_11-48-10_Unity.png](/img/avatars/vrcheadchop-example-setup-f0de7579-2024-03-15_19-52-11_Unity.png)

请注意，我们无需列出希望显示骨骼的任何子Transform（例如每一缕单独的头发），因为它们会连同根骨骼一起显示。将`VRCHeadChop`组件添加到哪个Transform上也无关紧要——唯一重要的是你在检视面板中为其设置的Transform列表。

结果如下：头发和耳朵已被重新放大，因此可以从第一人称视角看到；而眼睛仍被缩小，因此不会遮挡你的视野。

![vrcheadchop-618b6e18-2024-02-06_11-48-10_Unity.png](/img/avatars/vrcheadchop-example-result-f0de7579-2024-03-15_20-12-17_Unity.png)

你还可以使用动画器设置此组件的启用状态——如果组件被禁用，它将在再次启用之前不产生任何效果。这可用于设置表情开关，以控制Avatar的某些部分在第一人称视角中是否可见。建议你这样做，这样使用你Avatar的玩家就可以根据需要关闭第一人称可见功能。如果你希望更精细地控制骨骼被缩小的程度，可以使用动画器控制全局缩放。

## 其他用法 {#alternative-uses}

也可以通过将头部骨骼包含在列表中来直接更改头部骨骼本身的缩放。在这种情况下，VRChat将不再自动为你缩小头部骨骼，而是使用你为其提供的缩放系数。然后，你可以通过将缩放系数设为0来缩小头部中你*不*希望在第一人称视角中看到的子骨骼。如果采用此方法，你很可能需要缩小视角所在的那部分面部，以免佩戴者看到Avatar头部内部。

此组件的另一种用法是隐藏Avatar上其他不应在第一人称视角中看到的东西。例如，如果你的Avatar有一件权重绑定到头部但实际并非头部骨骼子级的兜帽，你可以使用此组件将其缩放系数设为0，从而在第一人称视角中将其隐藏。
