# 虚拟形象组件 {#avatar-components}

VRChat 的 SDK 包含一整套功能，可在虚拟形象之间创建有趣而激动人心的交互。

- [PhysBones](/common-components/physbones) 让骨骼可以受物理或其他玩家影响。
- [Contacts](/common-components/contacts) 可以检测碰撞，以触发动画或效果。
- [Constraints](/common-components/constraints) 会复制你虚拟形象上骨骼的运动。
- [Raycast](/avatars/avatar-components/raycast) 允许你发射可与世界或玩家碰撞的线或「射线」。
- [Head Chop](/avatars/avatar-components/vrc-headchop) 允许你在第一人称视角中隐藏或显示虚拟形象上的骨骼。

应用于虚拟形象的 PhysBones 和 Contacts 受[权限与设置](https://docs.vrchat.com/docs/permissions-and-settings)系统管理，它让你可以完全控制谁能与你交互。

通过试用 SDK 的示例虚拟形象来进一步了解 PhysBones 和 Contacts（'VRChat SDK > Samples > Avatar Dynamics Robot Avatar'）。
