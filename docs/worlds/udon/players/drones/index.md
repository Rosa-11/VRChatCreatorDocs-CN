# 无人机 API {#drone-api}

你可以使用 Udon 获取有关你世界实例中玩家无人机的信息。

Udon 通过 `VRCDroneApi` 与无人机交互。你可以从每个正在使用它的玩家那里获取 `VRCDroneApi` 对象。

你的世界可以检测无人机与触发器碰撞体的交互，并执行以下事件：

- [OnDroneTriggerEnter](/worlds/udon/players/drones/getting-drones#ondronetriggerenter)
- [OnDroneTriggerExit](/worlds/udon/players/drones/getting-drones#ondronetriggerexit)
- [OnDroneTriggerStay](/worlds/udon/players/drones/getting-drones#ondronetriggerstay)

有关通过 Udon 使用无人机的更多详情，请参阅以下页面：
* [获取无人机](/worlds/udon/players/drones/getting-drones)
* [无人机信息](/worlds/udon/players/drones/drone-information)
