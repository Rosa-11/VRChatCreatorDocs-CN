### VRCSDKBaseVRCInputMethod
`VRC.SDKBase.VRCInputMethod` 的类型定义。

| 索引 | VRCInputMethod     |
| ----- | ------------------ |
| 0     | Keyboard           |
| 1     | Mouse              |
| 2     | Controller         |
| 3     | Gaze               |
| 5     | Vive               |
| 6     | Oculus             |
| 7     | ViveXR             |
| 10    | Index              |
| 11    | HPMotionController |
| 12    | Osc                |
| 13    | QuestHands         |
| 14    | Generic            |
| 15    | Touch              |
| 16    | OpenXRGeneric      |
| 17    | Pico               |
| 18    | SteamVR2           |
| 19    | Embodied[^1]       |

[^1]: Embodied 表示用户正在使用某种手指追踪，例如手套或 VR 头显上基于摄像头的手指追踪。

:::note 含义模糊的 Vive 输入名称 

- `VRCInputMethod.Vive` 是通过 SteamVR 运行的 Vive 控制器。
- `VRCInputMethod.ViveXr` 是通过 OpenXR 运行的 Vive XR Elite 控制器。

:::
