# 网络 ID 工具 {#network-id-utility}
网络 ID 是用于在网络中确定哪个对象是哪个对象的标识符。在大多数情况下，你无需担心这一点，但在处理跨平台世界时可能会遇到，此时玩家实际上加载的是你世界的两个不同版本。

网络 ID 是这些不同版本之间的链接，用于确保每个人看到的内容一致，并且数据被传输到正确的对象。

更具体地说，网络 ID 只是一个分配给游戏对象的数字。例如，假设你有一个 ID 为 1 的沙滩球和一个 ID 为 2 的冰淇淋甜筒。如果这些被搞混了，那么你可能在踢一个沙滩球，而其他人却看到你在踢一个冰淇淋！

为了处理这些潜在问题并确保你的不同场景保持同步，我们创建了一个网络 ID 工具。

## 网络 ID 导入导出工具 {#network-id-import-and-export-utility}

该工具允许你在场景或项目之间保存和传输网络 ID。它可以在 Unity 编辑器中找到，路径为 `VRChat SDK/Utilities/Network ID Import and Export Utility`。

:::note

只有在你开发跨平台世界，且不同版本位于不同场景或项目中时，你才需要使用此工具。

:::

![network-id-utility-image1.png](/img/worlds/network-id-utility-image1.png)

使用此工具时，你会看到整个场景中所有网络 ID 的列表。如果你还没有这些内容，可以点击 Regenerate Scene IDs。

![network-id-utility-image4.png](/img/worlds/network-id-utility-image4.png)

当你准备好将一个场景的网络 ID 传输到另一个场景时，点击 **Export** 按钮将文件保存到某处。然后转到另一个场景，点击 **Import**，并选择该文件。


该工具会为每个对象的网络 ID 导出场景层级视图路径。例如：`{"10":"/CubePickup", "11":"/Prefabs/SyncedPen"}`。

当你将网络 ID 导入场景时，请确保每个联网对象的路径都相同。非联网对象无关紧要，它们可以在你的场景之间有所不同，只要它们不与确实需要同步的内容冲突即可。

:::warning

不要在网络游戏对象的名称中使用正斜杠 `/`。游戏对象路径依赖正斜杠作为分隔符，因此请避免使用它们，以防出现意外行为。

:::

![network-id-utility-image5.png](/img/worlds/network-id-utility-image5.png)

如果你的两个场景之间一切都匹配，你应该会看到一个大块，带有一个 **Accept All** 按钮。点击它即可，然后你就可以开始了！

## 解决冲突 {#resolving-conflicts}

该工具中包含若干冲突解决工具。要扫描冲突，请按 Scan For Conflicts 按钮，或勾选 Auto Scan 以在你于场景中工作时持续扫描。

![network-id-utility-image3.png](/img/worlds/network-id-utility-image3.png)

以下是一个存在于文件中但不存在于场景中的对象的示例。文件说此路径处有一个网络 ID，但它找不到具有该路径的对象。此时，你可以选择忽略它，或指定另一个对象。如果你确定这是一个不需要在此场景中存在的对象，那么你可以放心地忽略它。但是，如果它是一个应该存在于你场景中、只是名称不同的对象，那么你可以选择它。一旦你解决了此冲突，它就会下移到你可以接受网络 ID 的区域。

![network-id-utility-image2.png](/img/worlds/network-id-utility-image2.png)

这是另一个示例：某个对象说它的网络 ID 是 20，但文件说另一个不同路径应该拥有 20。

这种情况以及许多其他奇怪的情况，只会在场景在你尝试导入新文件覆盖之前就已存在网络 ID 时发生。如果你是在场景之间复制 ID，那么很可能你需要在导入前清除 ID，以免遇到此问题。不过，如果你需要做一些非常具体的事情，比如尝试在不破坏某些现有网络 ID 的情况下修复场景，这些选项确实存在。

如果你需要解决这些冲突，你可以选择点击 Ignore All 按钮，这完全不会改动场景；也可以手动挑选哪一个获得该 ID。当你点击 "Select" 按钮时，它会通过将 ID 应用到你已选择的对象来解决冲突。这可以解决一个或多个冲突，因此当你只解决一个冲突时如果许多冲突都消失了，请不要感到惊讶。
