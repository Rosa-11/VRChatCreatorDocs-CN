# 网络兼容性 {#network-compatibility}

如果你更新世界，它可能会与使用先前版本世界启动的所有活动VRChat实例不兼容。如果你修改通过网络同步数据的对象，并改变它们通信的方式或内容，就可能发生这种情况。

## 确定兼容性 {#determining-compatibility}

如果某个对象存在于世界的两个版本中，并且该对象同步网络数据，那么在以下条件下它_不兼容_：
- 它的组件类型、数量和**顺序**不匹配。
- _或者_组件的变量类型、数量和**顺序**不匹配。

向同步对象添加新组件或新的同步变量，很可能使世界上传的下一个版本与先前版本_不兼容_。

## 影响 {#impact}

当所做的更改使世界与先前版本不兼容时，任何加入使用先前世界版本启动的_活动_实例的用户都会收到通知，告知该实例正在使用不兼容的世界版本运行。该用户将被移出实例，并且必须确认该通知后才能继续使用VRChat。

当所有用户退出实例时，该实例会变为非活动状态。如果用户重新加入该实例，他们可以使用较新版本的世界，而不会触发兼容性问题。
