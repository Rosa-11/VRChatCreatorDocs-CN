你可以在VRChat世界中使用某些使用脚本的外部资源。

要查看VRChat世界中允许的精确组件列表，请参阅[允许的世界组件](/worlds/whitelisted-world-components)。其中大多数组件（TextMeshPro除外）在Quest上不可用。

## TextMeshPro
“TextMesh Pro是Unity的终极文本解决方案。它是Unity的UI Text与Text Mesh的完美替代品。”

自Unity 2018起，TextMesh Pro已成为Unity的内置组件。我们强烈建议使用TextMeshPro而非Unity内置的文本组件，因为它可以在任何字体大小或屏幕大小下提供高质量文本。

## Post Processing Stack v2
从Package Manager导入。

我们强烈建议查看[Silent的后处理指南](https://gitlab.com/s-ilent/SCSS/wikis/Other/Post-Processing)以获取更多信息和最佳实践。
:::caution 

导入后处理时，不要导入`Test`文件夹。它会导致脚本错误，从而阻止你上传世界。
:::
“后处理是在相机的图像缓冲区显示到屏幕之前，对其应用全屏滤镜和效果的过程。它可以用很少的设置时间大幅改善产品的视觉效果。”
