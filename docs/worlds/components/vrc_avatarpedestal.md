# VRC Avatar Pedestal

展示一个虚拟形象（Avatar），并允许用户与基座交互以切换为该虚拟形象。

你可以在SDK中找到一个名为 [AvatarPedestal](/worlds/examples/udon-example-scene#avatarpedestal) 的示例。该示例在用户与基座交互时调用 `SetAvatarUse` 方法。

## 参数 {#parameters}

| 参数            | 描述                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Blueprint Id         | 要展示的虚拟形象的Blueprint ID。                                                                                                                                                                                                                                                                                                                                                       |
| Placement（可选）  | 用于展示虚拟形象的变换。                                                                                                                                                                                                                                                                                                                                                          |
| Change Avatar On Use | 如果为 `true`，你可以调用 `SetAvatarUse` 来更改为本地玩家的虚拟形象。 |
| Scale                | 虚拟形象的大小。仅影响基座上的虚拟形象。                                                                                                                                                                                                                                                                                                                                                      |


## 虚拟形象所有权 {#avatar-ownership}

虚拟形象基座的行为取决于虚拟形象是公开的、私有的，还是在市场上发布的：

- 公开虚拟形象：所有用户都可以看到并使用该基座。
- 私有虚拟形象：只有上传者可以看到并使用该基座。其他用户会看到错误。
- [市场](/economy/store/avatar-marketplace)虚拟形象：所有用户都可以看到并使用该基座。如果用户不拥有该虚拟形象，他们会看到虚拟形象详情页面。
