# 平台 {#platforms}

VRChat SDK 允许你为以下平台上传世界和虚拟形象（Avatar）： 
- [Windows](/platforms/pc/)
  - VR 模式（配合兼容的 VR 设备）
  - 桌面模式
- [Android](/platforms/android/)
  - Meta Quest 2（或更新的设备）
  - PICO 4（或更新的设备）
  - HTC Vive XR Elite
  - 搭载 Android 10（或更高版本）的手机/平板
- [iOS](/platforms/iOS/)
  - 搭载 iOS 17.0（或更高版本）的 iPhone 和 iPad
