# 贡献指南 {#contribution-guide}

任何人都可以为 VRChat 创作文档提出改进建议！点击任意页面底部的“Edit this page”，并遵循 [GitHub 上的说明](https://github.com/vrchat-community/creator-docs/blob/main/README.md)。VRChat 会审核你的更改并将其发布。

以下指南说明了你应该如何编写和组织文档：

- [无障碍指南](./accessibility)
- [风格指南](./style) 
- [语法指南](./syntax) 

:::tip

使用“Feedback”按钮来建议简单的更改。我们会处理它！

:::
