# Aim约束 {#aim-constraint}

`VRCAimConstraint`组件会旋转目标变换，使其朝向源。你可以自定义将哪个方向视为前方。

![](/img/avatars/constraints/aim.png)

<ConstraintMainSettings />
- **Aim Vector** - 控制应朝向源的那些轴。
- **Up Vector** - 控制此约束的向上轴。这是受影响变换的轴，约束会尝试将其与下文定义的世界向上轴对齐。
- **World Up Type** - 控制此aim约束所使用的世界上方向。
  - **Scene Up** - 将场景的正Y轴视为向上。
  - **Object Up** - 将从约束的目标变换指向`World Up Object`属性中所指定变换的向量视为向上。
  - **Object Up Rotation** - 将`World Up Object`属性中所指定变换的局部空间中的`World Up Vector`轴视为向上。
  - **Vector** - 将世界空间中的`World Up Vector`视为向上。
  - **None** - 不定义向上方向。
