# 常用组件 {#common-components}

本页中的组件既可用于[虚拟形象](/avatars)，也可用于[世界](/worlds)。

- [PhysBones](/common-components/physbones)允许你虚拟形象上或世界中的骨骼受到物理或其他用户的影响。
- [接触器](/common-components/contacts)可以检测碰撞，以触发虚拟形象上的动画和效果，或世界中的 Udon 功能。
- [约束](/common-components/constraints)允许变换以复杂的方式相对于彼此移动。
