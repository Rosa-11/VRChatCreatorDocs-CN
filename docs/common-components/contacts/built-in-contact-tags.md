# 内置接触器标签 {#body-parts}

在处理接触器发送方和接收方时，VRChat SDK 提供了许多内置接触器标签供你使用。使用这些标签是可选的，如果你愿意，也可以自行输入任意文本作为标签，但使用内置标签能更容易地创建与你未参与制作的虚拟形象（Avatar）和世界兼容的接触器。例如，世界中可能有一个接收方用来响应虚拟形象的手，或者虚拟形象上有一个接收方用于响应触碰高温或低温表面。

要使用内置标签，请在检视面板的下拉列表中选择它，如下所示。请记住，你可以在一个发送方或接收方上组合使用多个标签——当发送方和接收方至少有一个共同标签时，接触器就会被触发。

## 身体部位 {#object-traits}

这一类标签描述人形虚拟形象的各个部位。

目前这是 VRChat 中唯一受到特殊处理的类别。当人形虚拟形象被加载时，如果虚拟形象作者没有手动定义，它会在相应骨骼上自动生成带有这些标签的接触器发送方。因此，通过在你的虚拟形象或世界中的接收方上使用这些标签，你就能够在这些身体部位靠近时检测到它们。这对于由触摸激活的功能很有用，例如摸别人的头，或世界中的按钮激活的机关。

| 标签            | 描述                                              |
|-----------------|---------------------------------------------------|
| `Head`          | 虚拟形象的头。                                    |
| `Torso`         | 虚拟形象的躯干。                                  |
| `Hand`          | 虚拟形象的任意一只手。                            |
| `HandL`         | 虚拟形象的左手。                                  |
| `HandR`         | 虚拟形象的右手。                                  |
| `Foot`          | 虚拟形象的任意一只脚。                            |
| `FootL`         | 虚拟形象的左脚。                                  |
| `FootR`         | 虚拟形象的右脚。                                  |
| `Finger`        | 虚拟形象任意一只手上的任意手指。                  |
| `FingerL`       | 虚拟形象左手上的任意手指。                        |
| `FingerR`       | 虚拟形象右手上的任意手指。                        |
| `FingerIndex`   | 虚拟形象任意一只手上的食指。                      |
| `FingerMiddle`  | 虚拟形象任意一只手上的中指。                      |
| `FingerRing`    | 虚拟形象任意一只手上的无名指。                    |
| `FingerLittle`  | 虚拟形象任意一只手上的小指。                      |
| `FingerIndexL`  | 虚拟形象左手上的食指。                            |
| `FingerMiddleL` | 虚拟形象左手上的中指。                            |
| `FingerRingL`   | 虚拟形象左手上的无名指。                          |
| `FingerLittleL` | 虚拟形象左手上的小指。                            |
| `FingerIndexR`  | 虚拟形象右手上的食指。                            |
| `FingerMiddleR` | 虚拟形象右手上的中指。                            |
| `FingerRingR`   | 虚拟形象右手上的无名指。                          |
| `FingerLittleR` | 虚拟形象右手上的小指。                            |

## 物体特性 {#elements}

这一类标签描述物体可能具有的特性。它们在 VRChat 客户端中没有特殊处理，但仍可能有助于创建跨多个虚拟形象和世界工作的系统。它们被细分为下面的几个小节。

### 元素 {#combat}

物体的元素属性。

| 标签      | 描述                                              |
|-----------|---------------------------------------------------|
| `Hot`     | 摸起来很热的物体或表面。                          |
| `Cold`    | 摸起来很冷的物体或表面。                          |
| `Fire`    | 火焰产生的火苗，或正在燃烧的物体。                |
| `Freezer` | 可以使与其接触的物体冻结的物体。                  |
| `Wet`     | 覆盖着液体的物体。                                |
| `Water`   | 液态水。很可能会使物体变湿。                      |
| `Wind`    | 施加风力的体积。                                  |

### 战斗 {#interaction}

可能与 VRChat 中的战斗系统相关的标签。

| 标签          | 描述                                                                              |
|---------------|-----------------------------------------------------------------------------------|
| `Weapon`      | 可用于作为武器的物体的通用标签。                                                  |
| `Shield`      | 可以阻挡或抵消伤害的物体的通用标签。                                              |
| `Damage`      | 任何接触时可能造成伤害的东西的通用标签。                                          |
| `DamageBlunt` | Damage的一个特定变体，用于钝器类伤害物体，例如棍棒。                              |
| `DamageSharp` | Damage的一个特定变体，用于利器类伤害物体，例如剑。                                |
| `Ammunition`  | 可作为远程武器弹药的物体。                                                        |
| `Projectile`  | 在空中飞行以造成伤害的物体，通常由武器发射。                                      |

### 交互

虚拟形象与其周围世界中物体之间的常见交互。

| 标签              | 描述                                                   |
|-------------------|--------------------------------------------------------|
| `Consumable`      | 某种消耗品，例如食物或药水。                           |
| `ConsumableFood`  | Consumable的一个变体，专用于食物类物品。               |
| `ConsumableDrink` | Consumable的一个变体，专用于饮品类物品。               |
| `Brush`           | 作用于头发、毛发等的刷子。                             |
| `Dye`             | 可以改变另一个物体颜色的物体。                         |
