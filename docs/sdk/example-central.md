# Example Central

Example Central为VRChat SDK提供了示例，你可以浏览、下载并修改这些示例，以便为自己的项目学习。

![Example Central窗口布局](/img/sdk/example-central/ec-layout.png)

:::info

Example Central才发布不久。

- 我们正在改进功能、设计和示例。
- 目前仅有世界示例可用，虚拟形象示例将在未来添加。
- 你可以在[Example Central Canny Board](https://feedback.vrchat.com/example-central)上向我们发送反馈。
- 你的VRChat账户的信任等级必须为“New User”或更高。

:::

## 基本用法 {#basic-usage}
从Unity编辑器菜单中的“VRChat SDK > 🏠 Example Central”打开该窗口

![从菜单打开Example Central](/img/sdk/example-central/ec-menu.png)

Example Central有两个主要部分——左侧的示例列表，以及右侧关于所选示例的信息。

![Example Central窗口布局](/img/sdk/example-central/ec-overlay.png)

* 浏览列表并选择一个示例，以查看更多关于它的信息。
* 选中后，示例的详细信息会显示在右侧。
* 按下“Docs”按钮，打开包含详细信息和使用该示例的演练的页面。
* 按下“Import”按钮，将示例的`.unitypackage`导入你的项目。

## 示例详情 {#example-details}

每个示例都有缩略图、标题、版本、标签、描述、指南和示例场景。世界示例还拥有一个已发布的VRChat世界。大量信息可帮助你快速上手！

### 版本 {#version}

每个示例都有版本指示器。当示例更新时，你会在Example Central中看到最新版本。

示例使用[语义化版本](https://semver.org/)。

:::warning

目前，你无法在导入示例后查看其版本。这使得你难以判断自己是否在使用最新版本。

未来，版本将包含发布说明，以及用于检查你是否使用最新版本的机制。

:::


### 标签 {#tags}

查看示例的标签，以快速了解其中涉及的系统与概念。你可以搜索任意标签来筛选示例列表。

### 指南 {#guide}

每个示例在Creator Docs中都有一份详细指南，你可以按下窗口中的“Docs”按钮来访问它。

### 示例世界 {#example-world}

在VRChat中访问示例世界，以更好地了解该示例在各平台上的运作方式！


### 设置 {#settings}

搜索框旁的齿轮图标（⚙）会打开Example Central的设置。

![Example Central窗口布局](/img/sdk/example-central/ec-settings.png)

有一个设置：
- 显示创作者经济示例

:::warning

该设置默认处于禁用状态，因为它目前正处于Beta测试阶段。你可以启用它，但如果你不是Beta测试者，示例将无法正常运行。

:::
