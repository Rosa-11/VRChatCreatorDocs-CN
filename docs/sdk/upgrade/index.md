# 管理Unity {#managing-unity}

如果你过去使用过VRChat SDK，你的项目可能仍在使用旧版本的Unity和VRChat SDK。要使用最新版本的VRChat SDK，你需要先更新Unity。

- 在你的电脑上[检查已安装的哪些Unity版本](unity-2022.md#managing-unity-versions)与VRChat兼容。
- 阅读我们的[Unity 2022迁移指南](/sdk/upgrade/unity-2022)，了解如何将Unity 2019项目升级到Unity 2022。
- 了解如何执行[Unity次要版本升级](/sdk/upgrade/migrating-to-a-newer-minor-unity-version)。

:::info 开始新项目？

阅读[设置SDK](/sdk/index.md)，了解如何使用VRChat最新的Unity SDK创建新项目。

:::
